# Haas Japanese Colab

Блокнот Google Colab для транскрибирования японских аудио- и видеофайлов с помощью Third Intelligence **Haas-ja-v1.0**.

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/piccoripico/haas-ja-colab/blob/main/notebooks/Haas_Japanese_Colab_ru.ipynb)

## Возможности

- **Бесплатно:** Работает в бесплатной среде GPU Google Colab.
- **Японский ASR:** Использует [`third-intelligence/Haas-ja-v1.0`](https://huggingface.co/third-intelligence/Haas-ja-v1.0), модель примерно с 0.6B параметров для распознавания японской речи.
- **Быстро:** Транскрипция может выполняться быстро.
- **Пунктуация:** Модель выводит оценочную японскую пунктуацию.
- **Временные метки и субтитры:** `subtitle` generates SRT with approximate chunk-boundary timestamps; `none` disables timing. Native word/character timestamps are unavailable.
- **Обработка длинных файлов:** Можно обрабатывать и длинные аудио- и видеофайлы.
- **Поддержка Google Drive:** Загружайте файлы напрямую или читайте их из Google Drive; выходной ZIP при необходимости можно сохранить на Drive.
- **Несколько форматов вывода:** TXT, Markdown, JSON, CSV, XLSX, SRT, manifest и ZIP.

## Использование

1. Выберите `INPUT_MODE` в **1. Settings** и при необходимости измените другие настройки.
2. Выберите **Runtime → Run all**.
3. При `INPUT_MODE = "upload"` выберите файлы в **2. File selection / Google Drive mount**.
4. Выходной ZIP автоматически загружается после завершения обработки.

## Режимы временных меток

- `none`: без временной информации.
- `subtitle`: SRT with approximate audio-chunk start/end times (not word-level alignment).

## Декодер

Haas-ja-v1.0 uses TDT only; CTC is unavailable.

## Длинные файлы

`CHUNK_SECONDS` задаёт внутреннюю длительность фрагмента для длинных файлов. Большие значения уменьшают число границ и сохраняют больше контекста, но делают каждый вывод тяжелее и могут увеличить использование памяти GPU. Меньшие значения облегчают каждый вывод, но создают больше границ, что может повлиять на распознавание рядом с ними. В большинстве случаев рекомендуется значение по умолчанию.

## Локализованный интерфейс

Сама модель ASR предназначена **только для японского языка**. Локализация README и интерфейса Colab охватывает все **183 активных языка ISO 639 Set 1** (устаревший `sh` исключён).

Английский (`en`) является каноническим источником перевода. Японский (`ja`) — проверенный перевод, который копируется в корень репозитория как представление `README.md` по умолчанию. Корневой японский README **не** используется как источник перевода. Остальные 181 локаль машинно переводятся с английского.

## Примечания

- Блокнот останавливается до транскрипции, если GPU недоступен.
- Время обработки зависит от длины входных данных, настроек и GPU, назначенного Colab. При первом запуске также загружаются NeMo и модель размером около 1.23 GB.
- Длинное аудио обрабатывается внутренними фрагментами, поэтому распознавание может ухудшаться возле границ фрагментов.

## Канонический источник и генерация

Канонические переводимые источники:

```text
source/README.en.md
notebooks/Haas_Japanese_Colab_en.ipynb
```

`locales/en.json` — синхронизированный канонический snapshot. Японский поддерживается как проверенный перевод в `locales/ja.json`, а его snapshot README копируется в корень как `README.md`.

```bash
python scripts/sync_from_english.py
python scripts/build_languages.py
python scripts/build_notebooks.py
python scripts/build_readmes.py
python scripts/check_repository.py
```

Поддержка переводов отделена от обычного CI. Обычным пользователям и CI не нужны учётные данные для перевода.
